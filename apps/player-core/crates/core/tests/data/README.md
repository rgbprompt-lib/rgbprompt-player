# `output_chain` corpus

`example-cyber-breath.lep` is copied from the golden fixtures generated by
`corepack pnpm player:fixtures` (`apps/player-core/fixtures/golden/`, which is
gitignored). It is the `example-cyber-breath` case: engine version `0.4.0`,
500 frames at 20 ms, no key or audio input, so it animates on its own.

`music-spectrum.lep` and `party.lep` are encoded from the committed examples
`packages/engine/data/examples/{music-spectrum,party}.json` with the engine's
server-side `normalize` → `validate` → `encode` chain (engine `0.4.0`). They
cover `EngineHost::input_wanted`: `music-spectrum` wants audio, `party` wants
both audio and keys.

The tests only decode these through the embedded engine; they do not read the
gitignored fixtures directory. `protocol-cases.json` is the public URL oracle.
`pnpm pins:check` compares its raw sha256 with `tools/golden/pins.json`.
